# MaterialShop

A Minecraft Paper barter shop: trade materials for materials. No money, no Vault, no economy plugin.
Companion to MaterialClaim. Built for Paper 26.3 (Banglaverse), Java + Bedrock through GeyserMC.

Work in progress: version 0.1.0. See [HANDOFF.md](HANDOFF.md).

## Build

`./gradlew build` produces `build/libs/MaterialShop-0.1.0.jar`.
GitHub Actions runs the same build and uploads the jar as an artifact on every push.
